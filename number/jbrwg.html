1减伤双轨：公式层

姜饼人王国的属性分三层：基础（详情页可见：生命 / 攻击 / 防御 / 暴击率 / 冷却）、 进阶（配料页可见：攻速 / 伤害减免 / 暴击抵抗 / 减益抵抗 / 增益增幅）、 隐藏（界面不显示：移速 / 暴伤 / 重量 / 减伤穿透 / 属性克制）。 分层的意义是：越强的属性越难被发现，而伤害减免这一条 —— 它同时是进阶属性、 社区公认的「最高价值副词条」，也是本作全部战斗公式的枢纽。

轨一 · 伤害减免 DR（乘法）

按百分比直接削减受到的伤害，是社区共识的第一优先副词条。有硬上限。

有效免伤 = MIN( DR × (1 − 穿透) , Cap )
Cap = 0.90（饼干） / 0.95（非 PVP 敌人）

穿透按乘法作用于对方的减伤值，不是加法减免 —— 这是本作 PVP 的核心对策位。

轨二 · 防御 DEF（另走一轨）

官方口径写的是「按固定值抵扣伤害（减法型）」。但本作 25 行实测数据不支持这个说法。

实测：免伤率 Q = DEF ÷ ( DEF + 6371 + 40 × 等级 )

DEF 不是直接抵扣，而是先转成一个百分比免伤率，再与 DR 相乘。两轨相乘，不是相加。

2免伤天花板

数值天花板被改过多次，其中改动最狠的一次是 v6.3（2025-04-09）： 伤害减免上限从 85% 到 90%。这个 5 个百分点不是小修 —— 它把坦度的理论上限 直接抬高了 50%。

为什么这次改动被标成「已验证」却值得单独记一笔
它是
一次数值改动 + 一次商业化动作 —— 存量 85% 满配玩家的边际收益从 「投入无效」变成「5pp提升空间」，把已封顶的养成线重新变成可售卖内容。
它不改
任何一条公式的结构，只改一个参数区的常数（Cap 0.85 → 0.90）， 所以页面上所有派生公式自动跟随，无需重算。

3免伤率函数：一条悬案如何闭合

此前的防御减伤与血量反推留下了一个明确的缺口： 从 25 行实测数据反解出的常数 c 不是一个常数， 也找不到与等级或攻击的单调关系 —— 于是初版给了一阶近似 Q ≈ D/(D + 7000)， 并列进「缺口与补全计划」。

3.1 缺口长什么样

战斗表的免伤率公式：实际伤害 = 技能系数 × 攻方攻击 × (1 − 伤害抵抗) × (1 − 免伤率)。 伤害要过两道闸：先被伤害抵抗按比例削，再被防御带来的免伤率削。 反解得到 25 行的 c 值：

缺口诊断：不是模型错，是噪声被读错了方向
当时的结论
「组内离散 5–6%，正好等于伤害浮动幅度 ±5%，说明 Q 的波动是测量噪声； 但 c 不是一个常数，也找不到与等级或攻击的单调关系。」
问题在哪
04 章把「组内离散小」当成了「噪声小」，然后拿 c 的点估计去比大小。 但 c 是 Q 的非线性变换的产物：c = J(1−Q)/Q， 它的相对误差被放大了 1/Q 倍 —— Q 越小，放大越狠。
正确做法
先做误差传播，再比较；而且比较要放在伤害域， 因为那里的噪声是恒定的 ±5%，不会被变换放大。

3.2 误差传播：c 的真实噪声有多大

观测伤害 O 带 ±5% 的浮动（战斗表 P 列用 INT(基准)×0.95 与 ×1.05 做上下界校验）。 于是免伤率 Q 的绝对噪声是 σ_Q = 5% × (1 − Q)，再传到 c：

σ_Q = 5% × (1 − Q)
σ_c = |∂c/∂Q| × σ_Q = ( DEF ÷ Q² ) × σ_Q
σ_c ÷ c ≈ 5% ÷ Q

这解释了三件当时看起来矛盾的事： 低免伤组（Q ≈ 15–20%）的 c 噪声高达 25%–33%； 高免伤组（Q ≈ 61–65%）的 c 噪声只有 7.7%–8.2%； 而 04 章观测到的「组内离散 5–6%」其实远小于真实噪声 —— 那几组只是恰好集中， 并不是噪声小。

同一个面板，为什么会测出好几个免伤率：
现象
lv17 组的守方面板完全相同（防御 5,719、等级 17）， 但战斗表里对应 6 行，免伤率分别是 46.36% / 43.63% / 46.11% / 43.92% / 43.81% / 42.65% —— 极差 3.71 个百分点。
原因
这 6 行的守方一样，但攻方不同（技能系数 0.09 与 0.157 交替出现， 观测伤害是 210 / 385 / 211 / 383 / 220 / 391.67）。 防御和等级只决定免伤率的中枢，实际观测值还要叠加伤害浮动， 所以同一面板出现多个免伤率是正常的。
方法学结论
按 (防御, 等级) 去重会静默丢掉 5 行， 只留第一行就等于拿点估计代表整组 —— 不严谨。 本页的 25 行样本逐行保留，把 25 个点全部画出来： 与模型值的最大偏差 2.21 个百分点，0 个超出 ±5pp。 （以组内均值看，lv17 这 6 行的均值是 44.41%，模型值 44.78% —— 差 0.37pp。）

总结
已闭合的
函数形态：免伤率 = DEF ÷ (DEF + a + b × 等级)， 即「DEF 转成减伤率后相乘，且分母含等级项」。这一条被 25 行实测数据判定。
未闭合的
两个常数的精确值。6371 与 40 是目前能给出的最佳估计， 不是被证实的真值。要进一步收紧，需要覆盖 lv100+ 的对照样本， 或一组「只动等级、其余锁死」的对照战。
因此
当时那条「c 不是常数、找不到单调关系」的缺口， 性质上是观测精度不足导致的误读，不是模型缺项。 正确的表述是：c 确实是随等级变化的常数族， 但变化幅度被 25 行样本的噪声掩盖了。

3.6 防御的边际效应：涨 12.8 倍，只换 4.3 倍免伤

公式闭合之后，DEF 的边际效应可以直接算了。25 行实测样本里，防御力从 1,177（lv7）到 15,078（lv45），跨度 12.81 倍； 而公式给出的减伤尺度 c 只从 6,651 涨到 8,171，仅 1.23 倍。 落到免伤率上：15.04% → 64.85%，只涨了 4.31 倍。

两条结论同时成立，它们不矛盾：

对同等级：饱和

同一等级内，DEF 翻倍带来的免伤增量越来越小 —— 这是一条典型的 D/(D+c) 饱和曲线，永远逼近上限但永不到达。

lv45：DEF 12,806 → 61.05%
lv45：DEF 15,078 → 64.85%
（防御 +17.7%，免伤 +3.81pp）

对跨等级：被稀释

等级每升一级，分母就多 40。DEF 涨得再快，也有一部分被等级项吃掉 —— 高等级角色的防御贡献被系统性稀释。

lv7 → c = 6,651
lv17 → c = 7,051（+6.0%）
lv45 → c = 8,171（+22.9%）
（分母每级 +40）

4DEF 存疑：减法型还是乘法型

官方口径（社区 wiki）写的是：防御 DEF = 按固定值抵扣伤害（减法型）。 若成立，被减免的伤害应当恒等于 DEF。但实测数据不是这样。

检验减法型的预言实测结果判定
伤害相对残差最大值≤ ±5%减法模型最大残差远超 5%否决

行 8 的伤害基数只有 68.5，DEF 却有 1,254 —— 若是减法型，这一击根本打不出来（减法模型给出负伤害）。 同一批数据里，行 11 的比值却逼近 0.99，减法型在那里「看起来对」。 比值从 1% 跑到 99%，恰恰说明它不是恒等于 1 的减法型； 高防端接近 1 只是大数巧合。

这个冲突有两种解释 ① 社区 wiki 口径本身有误； ② 战斗表与 wiki 取自不同版本，DEF 定义在版本间改过； 本作品采用实测口径（乘法型），并把这一条列入待验证清单。 它不影响本作品其余结论 —— 免伤率函数的闭合只依赖 DEF 与免伤率之间的映射关系，不依赖 DEF 在游戏内部的实现方式。

5伤害随机性

战斗表里有两组校验列，把随机性拆得很干净。这两条都是「已验证」级结论，但它们能解释 本作品为什么必须用 ±5% 的噪声界而不是更小的容差。

参数一 · 伤害浮动 ±5%

表内用 INT(基准)×0.95 与 ×1.05 作为上下界校验， 即每次伤害 = 基准 × U[0.95, 1.05]。

σ_O = 5% × O
→ σ_Q = 5% × (1 − Q)
→ σ_c ≈ 5% ÷ Q

这三级传递就是第 3.2 节误差传播链的来源。

参数二 · 暴伤抗 线性削减暴击倍率

普通伤害期望式写作 = 暴击伤害/2/(1.5−L) + 非暴击/2， 可见暴伤抗 L 直接从倍率里减，不是降低暴击概率。

暴击伤害 = 非暴击伤害 × (1.5 − 暴伤抗)

暴伤抗 0.078 → 倍率 1.422；堆到 0.5 → 倍率 1.0，暴击完全失效。

第二个参数的设计评价：线性封闭，但有断崖
优点
天生有上限（暴伤抗 < 0.5 才有意义），不需要额外钳制， 也不像「暴击伤害减免百分比」那样容易叠出无上限组合。
代价
收益曲线陡峭 —— 暴伤抗从 0.45 涨到 0.50， 暴击倍率从 1.05 掉到 1.00， 再堆 5% 就把整套暴击流废掉了。
迁移价值
这是「用线性封顶替代独立上限」的典型样本： 省掉一个参数，但把断崖风险从数值侧转移到配装侧。
